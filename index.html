GitHub につなぐ

商品データと画像は、データ用の非公開リポジトリに保存されます。トークンはこのブラウザの中だけに保存され、GitHub 以外には送られません。

トークンの作り方
  1. GitHub 右上のアイコン → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access で「Only select repositories」を選び、データ用リポジトリを選ぶ
  3. Permissions の Contents を「Read and write」にする
  4. Generate token を押し、表示された文字列をここに貼り付ける
